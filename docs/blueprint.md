# **App Name**: Property Parser

## Core Features:

- Input Area: Input text area where the user can paste the list of properties.
- Property Parsing: Process the input string to parse properties and their values, handling duplicates by keeping the last value.
- Output Display: Display the list of properties and values in a tabular format.

## Style Guidelines:

- Primary color: Light gray (#F0F0F0) for background.
- Secondary color: White (#FFFFFF) for content containers.
- Accent: Teal (#008080) for highlights and buttons.
- Use a clear, simple layout with the input area at the top and the output table below.
- Simple, outline-style icons for actions like 'copy' or 'clear'.
